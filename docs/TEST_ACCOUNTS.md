## 数据规则

- 测试账号带有可重复生成的体验数据，包括对话、成长卡片、能力线索、探索方向和月度总结。
- 每个测试账号的数据按用户 ID 隔离。
- 普通新注册用户首次进入时保持空白，只展示其后续产生的真实数据。
- 可通过 `tools/seed-test-accounts.mjs` 重置测试账号的体验数据；运行时必须从服务端环境文件读取云数据库配置。

## 发给测试者前

- 不要把服务端 `.env` 或 API Key 放入安装包。
- App 必须连接公网后端，不能使用 `127.0.0.1`。
- iPhone 外部分发使用 TestFlight；Android 外部分发使用签名 APK 或 AAB。
